Beyond chat

Claude does not only answer questions. Connected to our tools, it can do the work. (10 min)

Most people use Claude like a search box: ask, read the answer, copy it somewhere. That is only the first step. This page shows the next two, with a real example from our company.

Three ways to work with Claude

Step 1

Chat

YouaskClaudeanswersYou copy it

You ask, Claude answers. You paste in what it needs, and you carry the answer to where it belongs.

"Write a reply to this customer email."

Step 2

Chat with connectors

YouaskClaudereadsShopify, Notion, Drive

A connector lets Claude look inside the tools we already use. You stop copying and pasting, because Claude reads the real data itself.

"Look at this week's orders and tell me which products are running low."

Step 3

Claude Code

Youask onceClaude Codedoes every stepYou check

Claude Code is Claude with hands. It reads, then does the task from start to finish across several tools, and shows you what it did. You approve and check.

"Create a discount code for each person on this list, and make sure they work at the register."

The difference in one line: in chat, you do the work with Claude's help. With Claude Code, Claude does the work with your approval.

A real example: staff discount codes

Our store team shared one coupon code, so nobody knew who brought in which sale. One request fixed it.

The four levels

Everyone at Taimatsu starts at level 1. Nobody has to reach level 4 alone.

LevelWhat you doExampleWho
1 Chat Ask, read, check, use. Draft an email. Summarise a document. Translate. Everyone
2 Set it up once Use Projects, instructions and skills so you stop repeating yourself. A Project that knows your team's style and templates. Everyone
3 Connect Let Claude read the tools you work in, with connectors. "Find last month's meeting notes about the Kyoto store." Everyone, after reading Security
4 Automate Hand a whole repeated task to Claude Code. The staff discount codes above. A weekly report that builds itself. Built with your division's AI builder

Levels 1 to 3 are covered in Getting started. Level 4 is where the biggest time savings are, and it is a team effort: you know the task, the AI builder knows the tool.

Is my task worth automating?

A task is a good fit when you can say yes to all four:

  1. I repeat it. Every day, week or month.
  2. The steps are the same each time. I could write them down for a new colleague.
  3. It lives in our tools. Shopify, Notion, Google Drive, spreadsheets, email, chat.
  4. A person can check the result. I can tell quickly if it came out right.

Not a good fit: one-time work, decisions about people or money, and anything where a mistake cannot be undone.

Have a task like this? Bring it to your AI builder

You do not need to install Claude Code or learn it. Each division has an AI builder who sets these up. Your part is to describe the task well. Send them these four answers:

1. What is the task?
   Example: every Monday I copy last week's sales per store into the report.

2. How often, and how long does it take?
   Example: weekly, about 40 minutes.

3. Which tools does it touch?
   Example: Shopify, Excel, Chatwork.

4. What does the finished result look like?
   Example: one table per store, posted in the managers' chat.

Not sure who your AI builder is? Ask the engineering team.

Stay safe

More power means more care. Claude Code and connectors act in real systems, so the same habits apply: check the plan before you say go, never click "always allow" for sending, deleting or paying, and test the result yourself. Read Connecting email, files, and other tools before your first connector.
