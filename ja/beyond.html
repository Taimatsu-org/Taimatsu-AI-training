チャットの先へ

Claude は質問に答えるだけではありません。会社のツールとつなげば、仕事そのものを進められます。（10 分）

多くの人は Claude を検索窓のように使います。質問して、答えを読んで、どこかにコピーする。これは最初の一歩にすぎません。このページでは、その先の 2 つのステップを社内の実例と一緒に紹介します。

Claude の 3 つの使い方

ステップ 1

チャット

あなた質問Claude回答自分でコピー

あなたが聞き、Claude が答えます。必要な情報はあなたが貼り付け、答えもあなたが使う場所へ持っていきます。

「このお客様メールへの返信を書いて」

ステップ 2

チャット＋コネクタ

あなた質問Claude読むShopify、Notion、Drive

コネクタを使うと、Claude が普段使っているツールの中を見られます。Claude が実際のデータを自分で読むので、コピー＆ペーストが要らなくなります。

「今週の注文を見て、在庫が少なくなっている商品を教えて」

ステップ 3

Claude Code

あなた一度頼むClaude Code全部の手順を実行あなたが確認

Claude Code は「手を持った Claude」です。読むだけでなく、複数のツールをまたいで作業を最初から最後まで行い、何をしたかを見せてくれます。あなたは承認と確認をします。

「このリストの一人ひとりに割引コードを作って、レジで使えることも確認して」

ひとことで言うと、チャットでは Claude に手伝ってもらいながらあなたが作業します。Claude Code では、あなたの承認のもとで Claude が作業します。

実例：スタッフ別の割引コード

店舗チーム全員が同じクーポンコードを使っていたため、誰の接客で売れたのか分かりませんでした。それが 1 回の依頼で解決しました。

4 つのレベル

Taimatsu では全員がレベル 1 から始めます。レベル 4 を一人で目指す必要はありません。

レベルすること例対象
1 チャット 聞く、読む、確認する、使う。 メールの下書き、文書の要約、翻訳。 全員
2 一度だけ設定 プロジェクト、指示、スキルを使い、同じ説明を繰り返さない。 チームの文体やテンプレートを知っているプロジェクト。 全員
3 つなぐ コネクタで、普段使うツールを Claude が読めるようにする。 「先月の京都店についての議事録を探して」 全員（セキュリティを読んでから）
4 自動化 繰り返しの作業をまるごと Claude Code に任せる。 上のスタッフ別割引コード。自動でできあがる週次レポート。 部署の AI ビルダーと一緒に作る

レベル 1 から 3 ははじめにで説明しています。いちばん時間を節約できるのはレベル 4 で、これはチームで取り組みます。作業を知っているのはあなた、ツールを知っているのは AI ビルダーです。

この作業は自動化に向いている？

次の 4 つすべてに「はい」と言える作業が向いています。

  1. 繰り返している。毎日、毎週、または毎月。
  2. 手順が毎回同じ。新しい同僚に手順書として書ける。
  3. 会社のツールの中で行う。Shopify、Notion、Google ドライブ、スプレッドシート、メール、チャット。
  4. 人が結果を確認できる。正しくできたかすぐに分かる。

向いていないもの：一度きりの作業、人やお金に関する判断、間違えると元に戻せないもの。

そんな作業があれば、AI ビルダーに相談を

Claude Code をインストールしたり覚えたりする必要はありません。各部署に、こうした仕組みを作る AI ビルダーがいます。あなたの役割は、作業を分かりやすく伝えることです。次の 4 つを送ってください。

1. どんな作業ですか？
   例：毎週月曜に、先週の店舗別売上をレポートに転記している。

2. 頻度と、かかる時間は？
   例：週 1 回、約 40 分。

3. どのツールを使いますか？
   例：Shopify、Excel、Chatwork。

4. 完成形はどんなものですか？
   例：店舗ごとの表を 1 つずつ、マネージャーのチャットに投稿。

自分の部署の AI ビルダーが分からないときは、エンジニアチームに聞いてください。

安全に使う

できることが増えるほど、注意も必要です。Claude Code とコネクタは実際のシステムを操作するので、いつもの習慣を守りましょう。進める前にプランを確認する、送信・削除・支払いに「常に許可」を選ばない、結果は自分で確かめる。最初のコネクタをつなぐ前に、メールやファイルなどのサービスを接続するときを読んでください。

質問はエンジニアチームまで。
