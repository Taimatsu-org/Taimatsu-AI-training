Cheat sheet

Keep this page open.

Do

  • Use the company account
  • Give context: who, what, why, how
  • Replace real names and data with placeholders
  • Start a new chat for a new topic
  • Check every fact, number and date
  • Read every action before you click Allow
  • Report mistakes to the engineering team quickly

Don't

  • Use a personal or free AI account for work
  • Paste passwords, API keys or personal data
  • Trust files or links from unknown senders
  • Send or publish output without reading it
  • Click "always allow" for send / delete / pay
  • Put secrets in Project instructions
